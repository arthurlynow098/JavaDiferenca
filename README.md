# JavaDiferenca

## Sobre o projeto

Exercício Java que lê quatro inteiros e calcula `A × B − C × D`, exibindo o resultado no console.

## Como explorar

O arquivo declara a classe pública `Main`. Para compilar localmente, copie `DifencaJava.Java` para `Main.java` em uma pasta de trabalho e execute `javac Main.java`, seguido de `java Main`. Informe quatro inteiros; por exemplo, `5 6 7 8` resulta em `-26`.
